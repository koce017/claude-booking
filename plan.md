# Task
- The main goal is to make a website for booking appointments with various companies.
- Users can select which company the want to book an appointment with. After selecting, a calendar like interface will appear, in which users can view an hour by hour breakdown of each day. Every hour can either be booked or free or a non working hour. Users can than select an hour and make an appointment for that hour. Upon making an appointment, a request gets sent to the site admins to approve the appointment.
- Administrators manage the website. They can add or remove available companies, deny or approve booking requests, edit parameters related to the company(work days, work hours, etc.).

# Main website working principles
- Users don't need an account to make bookings. They can freely view available appointments and make requests. When they book an appointment, they leave their informatine(name, phone number, email).

# Importan note
- What happens with the booking requests once they are approved is subject to change. The information might automatically be passed on to the companies, or the admins might manually deliver that information to them. While working on the website, make sure this perticialr part of it can be changed easily, without impacting other systems.
